# Termômetro das Competências — simulador do mobiliário

Simulador 3D (three.js) do mobiliário do Termômetro das Competências: caixa de transporte em MDF com estrutura de alumínio, tampa com os copos de fixação dos tubos de acrílico, suportes internos e bolinhas.

Abrir: https://carribeiro.github.io/termometro-competencias-simulador/

Arquivo único (`index.html`); as bibliotecas vêm do jsDelivr (three.js 0.160.0, polygon-clipping 0.15.7).
